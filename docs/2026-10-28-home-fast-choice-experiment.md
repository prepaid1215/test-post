# 홈 전환 우선안 · 2026-10-28

## 선택한 전략
가장 먼저 해야 할 일은 **광고형 스토리의 분량을 늘리는 것**이 아니라, 첫 화면에서 소비자가 자신의 사용 패턴을 한 번 선택하게 하고 그 결과로 특정 요금제를 바로 보여주는 것입니다. 긴 3문항 설문 대신 한 번의 선택으로 상품명·가격·기본 데이터·소진 후 속도·선택 이유를 표시합니다.

### 실제 구현
- 홈 상단 우측 기존 7GB 고정 장식 카드를 3선택 빠른 비교 도구로 교체.
- 와이파이 위주 → L망 7GB+ (스토리형 상세페이지).
- SNS/영상 가끔 → K망 15GB+(밀리의서재) (15GB 카테고리의 해당 상품 강조).
- 외부 데이터 많이 → K망 100GB+(밀리의서재) (100GB 카테고리의 해당 상품 강조).
- 가입 방식(번호이동/신규가입/미정)은 추가 선택사항이며 링크로 연결됩니다.
- 7GB 상품은 번호이동/신규가입 가능 여부가 확인되지 않아 해당 방식으로 선택 시 별도 확인 문구를 보여줍니다.
- 15GB/100GB 목록에서는 홈에서 고른 상품을 시각적으로 강조하고, 가입 유형 선택은 공식 안내 팝업에서 유지합니다.
- 구매상세페이지에서는 홈에서 선택한 가입 방식을 이어 받습니다.
- 기존 상품·검색·스토리·계산기·19개 SEO 랜딩페이지·1개 상세페이지는 그대로 둡니다.

### 가격과 동선 한계
- 가격은 **2026년 9월 스냅샷** 기준입니다. 실제 판매 여부와 유심 호환, 가입 승인 여부를 보장하지 않습니다.
- 상세페이지가 없는 15GB/100GB는 해당 카테고리의 선택 상품으로 연결됩니다.
- 공식 상품별 개통 딥링크는 검증되지 않았으므로 만들지 않습니다.

### 관측 계획
- dataLayer: home_match_choice (사용 패턴과 상품), home_match_join_method (가입 유형), home_cta_click (매칭 결과 클릭).
- 기존 catalog_plan_selected 및 catalog_official_click, story_official_click으로 이어지는 흐름을 본 뒤 실제 개통 승인·완료 데이터와 대조해야 합니다.
- GA4/GTM 실연동 및 완료 실적 연결은 아직 없습니다. 전환율 상승을 입증하거나 보장하지 않습니다.
