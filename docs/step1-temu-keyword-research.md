## 확인된 설계 요소
1. 메인에 종합 혜택·카드·설명·행동 버튼을 함께 둔다.
2. 별도 페이지는 오타/금액/첫 구매/행사 등 다른 질문으로 분리한다.
3. 각 상세 페이지에서도 관련 상품 및 행동으로 연결한다.
4. 혜택 정보와 실제 혜택 조건의 현재 유효성은 별도 검증이 필요하다.

## 아직 검증되지 않은 것
- 네이버·구글 검색어 40개 각각의 실제 현재 노출 URL과 순위.
- 이런 URL 구분 방식이 실제 노출량 증가의 원인이었는지.
- 검색자 유형에 따라 다른 콘텐츠를 보여주거나 리디렉션하는 수법은 적용하지 않는다.

## 후불 알뜰폰으로 번역한 기준
- 오타/유사표현이 같은 검색 의도면 같은 대표 URL에 자연스럽게 포함한다.
- 가격·데이터·번호이동·단말·혜택처럼 답이 달라지면 별도 콘텐츠와 URL을 제공한다.
- 최소 기본료를 시장 전체 최저가라고 홍보하지 않는다(현재 상품자료는 앤텔레콤 후불 일부).
- 유입→상품선택→공식 후불 가입 또는 상담. 절대 선불폰으로 이동시키지 않는다.
