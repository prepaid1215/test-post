# 앤텔레콤을 선택할 이유 — 5개 검색 랜딩에 반영 (2026-10-28)

## 발견된 문제
0원 광고형 랜딩은 타사 광고의 위험만 설명하고 **왜 우리 앤텔레콤 상품을 선택할지**에 대한 설득 근거가 없었다. 기존 4개 실험도 키워드 질문에는 답했지만 사업자와 상품의 차별화가 약했다.

## 구체적인 선택 이유
- L망 7GB+ 월 17,900원 · 7GB + 소진 후 최대 1Mbps · 일반통화·문자 기본제공. 와이파이 중심, 혜택보다 기본료 중시.
- K망 7GB+(밀리의서재) 월 19,500원 · 7GB+1Mbps + 밀리의서재 구독권 · 2026년 K망 선정 제휴요금제 추가 데이터 10GB/24개월 홍보. **이벤트 대상, 가입 시점과 유지 조건 검증 전에는 보장하지 않음.**
- K망 7GB+(네이버페이) 월 21,100원 · 별도 5,000P 쿠폰 조건(30일 사용·31일차 유지·기프티쇼 발송·등록기한). 실청구 16,100원으로 표시하지 않음.
- 100GB를 실제로 쓰는 고객에게는 K망 100GB+(밀리의서재) 월 43,200원, 소진 후 최대 5Mbps(조사 시점).
- 고객은 '0원 후 가격'뿐 아니라 자기 데이터 사용량, 쿠폰 활용도, 신청 유형, 실사용 조건을 확인할 수 있음.
- 운영자 59만모바일을 통한 상담 지원은 **설명·안내**이지 가입 승인이나 특별한 독점 할인을 약속하는 것이 아님.

## 페이지별 적용
- 0원 광고형: '왜 앤텔레콤?'을 광고 유형 설명보다 앞에 배치. L7 기본료, K7 밀리, K7 네이버페이 3상품. 첫 화면 CTA를 선택 근거 영역으로 변경.
- 1만원대: L7 기본료형 / K7 밀리 제휴형.
- 번호이동: K7 밀리 / L7와 번호이동 조건 점검.
- 무제한: K7 밀리 / L7 비교 + 100GB 밀리 바로 비교 동선.
