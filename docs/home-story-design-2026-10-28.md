# 2026-10-28 스토리형 쇼핑 홈 리디자인

## 실제 전환 설계
- 홈 상단: 방문자가 자신의 데이터 사용 환경과 비용 고민을 인식하도록 짧게 설명
- 상황 선택: 통신비 부담 / 데이터 부족 / 번호이동 / 제휴혜택을 각각 기존 검색 URL로 연결
- 상품 스토리: L망 7GB+ (상세페이지 직행), K망 15GB+(밀리의서재) (15GB 목록), K망 100GB+(밀리의서재) (100GB 목록)
- 통신비 계산: 현재 요금과 선택 상품의 **조사 월 기본료 차이**만 표시. 12개월 차이는 같은 요금 유지 가정이며 실제 절감 보장은 아님
- 개통 안내: 번호이동·신규가입·기기 호환 조건 확인
- CTA: 전면에 상세페이지와 공식 가입 안내를 구분; 직접 신청 URL을 확인하지 않은 상품에는 가짜 직접 신청 딥링크를 만들지 않음

## UI 디자인
KT M모바일 다이렉트몰에서 참고한 화이트/블랙/핑크 중심의 신뢰감 있는 색상과 여백은 유지하되 자사 로고 및 독립 디자인을 적용. 대형 장식용 이미지나 가짜 후기, 허위 추천 순위는 없음.

## 사이트 구조 및 계측
- / 는 홈으로 분리하고 원래 19개 검색 URL은 유지.
- /plans/ 는 47개 상품 카탈로그.
- /plans/l-7gb/ 는 완성된 개별 구매상세페이지.
- 홈 dataLayer 이벤트: home_cta_click, home_savings_plan_changed, home_savings_calculated.
- GA4/GTM 연결과 실제 승인 개통 추적은 별도로 필요. 버튼 클릭은 개통 완료가 아님.
