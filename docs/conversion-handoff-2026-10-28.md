# 알뜰폰 요금제 전환 개선 2026-10-28

## 개선 내용
- 모든 19개 검색 페이지에서 상품 카드별 선택 버튼을 누르면 동일한 공식 상품 목록으로 갑자기 이동하지 않고 **선택 상품명·기본료·데이터·통신망 요약**을 먼저 확인할 수 있습니다.
- 사용자는 **번호이동**(현재 번호 유지) 또는 **신규가입**(별도 회선 가입)을 선택하고 공식 가입 조건을 읽거나 상담으로 갈 수 있습니다.
- 개별 상품에 대응하는 공식 신청 딥링크를 확인하지 못한 상황입니다. 따라서 공식 목록 이동만 제공하고, 동일한 상품을 다시 찾기 쉽도록 상품명을 복사할 수 있게 합니다. 개별 상품을 자동 선택한다고 주장하지 않습니다.
- 검색 주제에서 예산형·데이터형·번호이동으로 빠르게 갈 수 있도록 상단 바로가기 3개를 추가했습니다.
- 모바일 하단 바는 선택한 상품이 없을 때 요금제 목록으로, 상품을 선택한 뒤에는 그 상품의 가입 안내로 열립니다.
- 사용자 개인정보/인증수단은 사이트에서 수집하지 않습니다. 판매조건은 2026-09-28 조사 기준입니다.

## 데이터 레이어 이벤트 (전송 활성화 아님)
- `catalog_plan_selected`: 어떤 상품이 선택됐는지
- `catalog_join_method`: 번호이동/신규가입의 선택
- `catalog_plan_name_copied`: 공식 상품명 복사
- `catalog_official_click`: 선택 상품에서 공식 페이지 이동
- `catalog_chat_click`: 선택 상품에서 카카오 상담 이동
- 기존 `catalog_filter`, `catalog_compare_open` 유지

## 이 개선으로 해결하지 못한 것
1. 공식 사이트의 상품별 직접 가입 링크가 확인되지 않았습니다. 따라서 실제 신청 전에 동일한 요금제를 수동으로 찾아야 할 수 있습니다.
2. GA4/GTM 구성 및 공식 개통 실적 연동은 별도 작업입니다. 이벤트가 dataLayer에 쌓인다는 사실만으로 측정이 완료되었다고 주장하면 안 됩니다.
3. 실시간 요금제·프로모션 동기화와 가입 자격 검증이 되지 않습니다. 이 UI 개선이 개통률 증가를 보장하지 않습니다.
4. 자동 검사는 HTML·JS 문법·내부링크 검사입니다. 실제 브라우저에서의 화면/이용자 경험을 별도로 점검해야 합니다.
